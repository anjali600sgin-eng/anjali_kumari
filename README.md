# Plixora - Online Gaming Website

PRD and documentation for Plixora, a free browser gaming portal built on the PERN stack.

## What's in here

| File | What it covers |
|---|---|
| overview.txt | Quick summary of the product |
| scope_of_work.txt | What gets built, front to back |
| assets.pdf | Full PRD with brand guidelines, screens, and specs |
| reference_image.png | Approved UI mockup |
| instructions.md | Detailed build instructions for developers |
| rubrics.txt | 40 acceptance criteria for grading deliverables |

## About Plixora

Plixora is a free online gaming site where you pick a game and play instantly in the browser. No downloads, no sign up required. Built with PostgreSQL, Express, React, and Node.js.
